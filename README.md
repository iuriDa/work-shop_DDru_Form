# Double Dutch Registration — direct Apps Script

Форма отправляет данные напрямую в Google Apps Script.

## Важно
1. В Google Apps Script замените весь `Код.gs` содержимым файла `APPS_SCRIPT.gs`.
2. Нажмите **Начать развертывание → Управление развертываниями → Изменить**.
3. Выберите **Новая версия** и нажмите **Развернуть**.
4. URL `/exec` должен остаться тем же.
5. Загрузите `index.html` и остальные файлы этого проекта в GitHub. Vercel передеплоится автоматически.

`api/register.js` и `vercel.json` больше не используются.
